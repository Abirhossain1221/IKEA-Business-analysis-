# IKEA Business Analysis

## Project Overview
This project analyzes IKEA sales data using Power BI to identify sales trends, product performance, and business insights.

## Tools & Technologies
- PostgreSQL – Database creation and merging two tables.
- Python – Data cleaning and transforming data into a final CSV file for RFM analysis.
- Power BI – Interactive dashboard development and data visualization.
- Power Query
- DAX

## Project Workflow
-Imported sales data into PostgreSQL.
-Created a database and merged two tables using SQL.
-Cleaned and processed the data using Python.
-Exported the final dataset to CSV for RFM analysis.
-Built an interactive Power BI dashboard to visualize insights.

## Key Features
- Sales performance analysis
- Product-level insights
- Interactive dashboard
- Data cleaning and transformation
