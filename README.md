# IKEA Business Analysis

## Project Overview
This project analyzes IKEA sales data using Power BI to identify sales trends, product performance, and business insights.

## Tools & Technologies
- Power BI
- Power Query
- DAX

## Key Features
- Sales performance analysis
- Product-level insights
- Interactive dashboard
- Data cleaning and transformation
